# 资源生态管理系统

基于 Vue 3 + Element Plus + ECharts 构建的教学资源生态管理后台系统，涵盖数据驾驶舱、资源全生命周期管理、统计分析、分类标签体系、用户权限控制、系统运维等六大核心模块。

## How to Run

```bash
docker-compose up --build -d
```

启动后访问：http://localhost:8081

- 管理后台：http://localhost:8081
- 后端 API：http://localhost:3000/api

## Services

| 服务 | 端口 | 说明 |
|------|------|------|
| backend | 3000 | 后端 API（Express + SQLite） |
| frontend-admin | 8081 | 管理后台（Vue 3 + Nginx） |

## 题目内容

开发一个教学资源生态管理系统，包含以下六大功能模块：

1. **数据驾驶舱（首页）**：多维度数据卡片（总资源数、新增资源、下载量、待审核）、高频资源 TOP5 轮播、年级访问量柱状图、上传/下载双轴折线图、资源类型环形图、审核时效柱状图、知识点覆盖雷达图、快捷操作入口、预警提示

2. **资源全生命周期管理**：拖拽上传与分步表单、多维度筛选（年级/类型/关键词）、列表/网格双视图、审核队列（优先级排序、通过/驳回）、版本管理与归档

3. **资源统计与精准分析**：学科下载量 TOP10 柱状图、使用时段热力图、曝光→使用转化漏斗图、教师贡献排名卡片、健康度散点图、教研组堆叠柱状图、TOP50 唯一表格、自定义报表导出

4. **资源分类与标签体系管理**：四级分类树（可拖拽）、分类使用率饼图、热门标签云、标签关联环形图、智能打标建议、分类覆盖率对比柱状图、活跃度折线图、优化建议

5. **用户权限与资源访问控制**：角色卡片管理、权限矩阵（开关配置）、权限使用频次图表、访问日志、资源级/操作级权限、用户画像与智能推荐

6. **系统运维与数据保障**：系统配置表单、数据备份（周期/范围/进度）、CPU/内存/磁盘仪表盘、接口响应折线图、并发访问柱状图、操作日志、冗余数据清理

### 技术要求

- Vue 3 + Vite + Element Plus + ECharts
- 不使用 Pinia / Vuex
- 独立登录页，登录后才能访问系统
- 所有组件占满屏幕，支持滚动
- 图表图例与标注不重叠
